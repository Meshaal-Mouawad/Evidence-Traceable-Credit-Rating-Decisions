JFRC anonymous manuscript LaTeX source
Entry point: main.tex. Compile with a complete TeX Live installation:
    bash build_submission.sh
The resulting main.pdf corresponds to the separately supplied anonymous article.
Tables are separate files; their editable sources and standalone wrappers are in tables/.
All manuscript, bibliography, figure and table source bytes are retained from the approved package.
This package contains no author title page or internal editorial reports.
For ScholarOne use: Supplementary File Not For Review (Emerald's LaTeX instruction).
